# Video to Whitemodel Previz

以原片畫面為證據，在 Blender 4.x 建立簡化人物與場景，保留剪接、透視、運鏡、動作及前後遮擋。
這是一份流程包裝；依環境使用既有工具，工作產物寫入任務目錄，不將程式、權重或影片加入 skill。
白模可省略材質與細節，但不能省略影響投影、運動或遮擋的幾何。

## 1. 取得原片與分鏡

1. 接收本機影片或來源網址；遠端用 yt-dlp 下載，必要時加入 JavaScript runtime，如 Deno。
2. 用 ffprobe 記錄解析度、像素比例、實際幀率分數、幀數、時間戳與音訊；保留原片。
3. 若為可變幀率，建立固定幀率工作副本並保存原始時間戳至工作格的映射；後續統一使用此基準。
4. 偵測切鏡後逐格複核，將所有切點對齊整數格；淡入淡出、疊化與遮擋轉場另列區間。
5. 建立 shot list，每鏡包含下列欄位，並抽取首、中、尾與運動變化格供檢視。

| 欄位 | 內容 |
| --- | --- |
| `shot_id` | 穩定且唯一的鏡頭識別碼 |
| `start_frame`, `end_frame_exclusive` | 零起算、左閉右開的工作格範圍 |
| `fps`, `source_time_range` | 幀率分數與原片時間範圍 |
| `scene_id`, `subjects`, `camera_motion` | 場景關聯、人物 ID、觀察到的運鏡 |
| `transition_ranges`, `uncertainty` | 轉場／特效範圍與不確定處 |

Blender 若從第 1 格開始，明確保存 `blender_frame = source_frame + 1` 的映射。
不要從四捨五入的秒數反推切點，也不要讓重新編碼或抽格改變時間基準。

## 2. 分層追蹤與保留驗證格

1. 每鏡在地板接縫、牆角、招牌邊角等靜態背景打點，涵蓋畫面不同區域與可見深度。
2. 排除滑動、漂移及跨切鏡的軌跡；以消失線、平面及固定邊緣補充空間約束。
3. 對每個人物獨立追蹤頭、骨盆與左右腳，保存 ID、可見性及信心值，避免人物交換。
4. 閃光、反射、人物遮擋分開遮罩；動態螢幕、粒子與疊圖也不可當成靜態背景點。
5. 在擬合前固定 held-out frames，例如保留約 20% 的有效格，分布於鏡頭不同時間與運動階段。
6. held-out 格的人工標記與觀測不得參與相機、幾何、動作擬合或超參數調整；保存明確格號。

短鏡頭也須保留獨立驗證格；若有效觀測不足，標記證據不足，不可用訓練格誤差冒充驗證結果。
一旦依 held-out 結果修改模型，原集合視為開發驗證；最終驗收須另留未使用的格或獨立標記。

## 3. 解算相機與一致空間

1. 使用 Blender camera tracking 或 COLMAP，以有效背景點解焦距／內參、相機姿態與路徑。
2. 視素材處理畸變、裁切與變焦；記錄假設，避免把後製畫面位移誤解成相機平移。
3. 從地面、牆面與背景點建立簡化幾何，校核消失線、透視及多格視差。
4. 以可靠尺寸或明示的尺度錨點建立地面、座標軸及場景尺度；單目無法確定絕對尺度時標註相對尺度。
5. 同一場景跨鏡沿用一致幾何與尺度，禁止逐鏡任意縮放背景以掩蓋相機誤差。
6. 在擬合格降低重投影殘差後，將解算結果導入 Blender，保留追蹤點及相機對應紀錄。

**禁止用目測加 lens shift 取代相機解算。** 人物頭部置中或單點投影吻合，不能證明焦距、路徑與透視正確。
只有具備校準或後製證據時才使用 lens shift，且須一併通過背景重投影驗證。
純旋轉、平面或低視差鏡頭可能退化；改用受約束的平面／旋轉模型並揭露無法辨識的自由度。
無法可靠解算的鏡頭應列為待修正，手動近似須明示，不能宣稱已還原。

## 4. 還原人物走位與動作

1. 使用 MediaPipe、DWPose、WHAM 等姿勢估計工具，提取逐人關節、根節點軌跡與信心值。
2. 2D 姿勢需結合已解相機、地面接觸及尺度約束提升至 3D；不得把螢幕座標直接當世界座標。
3. 將動作重定向至簡化白模骨架，處理骨長、前後深度、轉身及多人物相對站位。
4. 對低信心或遮擋片段做人工校正與短段插補，保留不確定標記；檢查腳底接觸、滑步及穿地。
5. 烘焙實際動畫後，重新投影頭、骨盆、腳與人物包圍框，校核相機構圖、人物大小及前後遮擋。

禁止以正弦擺動、循環假舞步或固定隊形取代原片動作；程序工具只可協助清理已追蹤的動作。
不要以靜態瞄準點代替實際動畫後的位置；動作修正後必須重查畫面。
若人物誤差仍高，先判斷是 root motion、姿勢、尺度還是相機問題，避免為人物誤差破壞背景解算。

## 5. 分段處理遮擋換景與特效

1. 將遮擋換景、合成特效、閃光及不可連續解算的片段標成獨立區間，必要時分開求解前後相機。
2. 換景前後各自保持地面與場景座標一致，明確記錄空間銜接；有實體遮擋物時以簡化幾何還原。
3. 排除這些區間的相機誤差統計，並記錄排除格號、原因、有效樣本數及覆蓋率。
4. 仍須檢查轉場切點、遮擋順序、出入畫時機及視覺連續性；排除相機統計不代表免驗收。

排除範圍在評估前確定，不得為了讓數字通過而擴大；完全無有效背景的區段回報不可量測。
被排除區段不能以零誤差計入平均，也不能隱藏在全片平均值中。

## 6. 先驗單鏡，再驗全片

先逐鏡低解析度試渲，用相同格號、畫幅及時間基準比較原片與白模，再播放連續片段檢查速度。
不可為降低誤差而額外平移、縮放、裁切或扭曲評估影像；必要的鏡頭校正須對兩者一致並記錄。
在渲染前固定以下可調門檻；下表是建議起點，按素材解析度與用途調整，記錄理由。
`W`、`H` 為評估影像尺寸，`D` 為對角線；位置統一正規化，速度以每秒計算。

| 門檻欄位 | 建議預設值（可調） | held-out 比對與失敗退回 |
| --- | --- | --- |
| `cut_error_frames_max` | 0 格 | 全部切點逐格吻合；失敗回步驟 1 |
| `bg_reprojection_p95_diag` | ≤ 0.005 | 背景點重投影像素距離 / D 的 P95；回步驟 2–3 |
| `person_center_p95_diag` | ≤ 0.02 | 逐人可見包圍框中心距離 / D 的 P95；回步驟 3–4 |
| `person_size_rel_p95` | ≤ 0.10 | 包圍框寬、高相對原片誤差的 P95，各自過關；回步驟 4，再查步驟 3 |
| `occlusion_order_match_min` | ≥ 0.95 | 可判定遮擋關係的正確比例；回步驟 4–5 |
| `occlusion_event_error_frames_max` | ≤ 1 格 | 遮擋進入／離開時點差；回步驟 4–5 |
| `motion_direction_p95_deg` | ≤ 10° | 背景點與人物中心分組比較位移向量夾角 P95；回步驟 3 或 4 |
| `motion_speed_rel_p95` | ≤ 0.15 | 同組影像平面速度相對誤差 P95；回步驟 3 或 4 |
| `stationary_speed_max_diag_s` | ≤ 0.005 | 原片低於此速度時改驗白模絕對速度 / D；回步驟 3 或 4 |

運動向量使用相同時間窗的相鄰驗證格；窗內不得跨切鏡、遮罩或排除區段。
近靜止樣本不計方向角與相對速度，改用靜止速度門檻，避免除以接近零的速度。
人物尺寸只比較有效且一致的可見範圍；完全遮擋樣本不填零，另報缺測與覆蓋率。
背景與各人物分別判定，保存逐格結果、P95、最大值及失敗格，禁止以全片平均掩蓋單鏡失敗。
樣本不足或必要項目不可量測時，標記未通過並附原因，不可自動放行。

量化之外，必須看 held-out 原片／白模並排與疊圖，確認透視、輪廓、景深層次及遮擋合理。
輪廓 IoU 或邊緣相似度可作輔助，不能當成相機準確度或整體還原百分比。
任一必要門檻未過或畫面明顯不符，就回到表中對應步驟，修正後重新驗收。
所有單鏡通過後才整片渲染；全片重查鏡頭順序、切點、跨鏡尺度、動作速度與轉場連續性。
格數、幀率、長度及可解碼檢查仍須通過，但不能取代上述畫面驗收。

## 7. Call Codex／agy-run review

此類「還原原片」任務的 agy-run review 必須明確要求原片對白模的視覺比對，並附量化 metrics。
這屬於 **joe 主動要求的 visual QA 例外**；不得只要求檢查格數、幀率、長度或檔案存在。
若 Call Codex／agy-run 可用，將下列要求連同素材位置、shot list、門檻及排除區間交給 reviewer：

> 請逐鏡查看 held-out 原片／白模並排與疊圖，並播放運動片段。
> 核對 metrics.json 的背景重投影、人物中心與大小、遮擋、方向、速度及逐格切點。
> 列出每鏡 pass/fail、失敗格、畫面證據與應退回的步驟，再檢查全片連續性。
> 不能僅憑格數、幀率、長度通過；無法讀取或觀看畫面時回報 review 未完成。

工具不可用時記錄限制，執行同等視覺與量化檢查；不得宣稱已通過 agy-run review。

## 8. 交付

- 原片與白模的並排對照影片：同格同步、相同畫幅，標示 shot ID 與來源格號。
- `metrics.json`：來源與時間映射、評估尺寸、門檻、擬合／held-out 格、遮罩與排除區間。
  同檔保存每鏡逐格量測、彙總值、有效樣本數／覆蓋率、缺測原因及視覺 review 結果。
- 每鏡 pass/fail 清單：逐項門檻結果、失敗格與證據、待修正步驟；分列轉場與特效的驗收狀態。

若仍有未通過鏡頭，以未完成預演交付並列出缺口，不可將輸出規格合格寫成還原驗收通過。
