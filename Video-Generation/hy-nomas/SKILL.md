# Hy-Nomas: Towards Free-Form Interactive World Generation

Hy-Nomas 是騰訊 Hy Visual Generation Team 的互動式世界模型。它結合語言、相機運動與視覺記憶，讓使用者逐輪決定接下來發生什麼。

## 互動能力

- **多輪文字控制**　使用者可持續用提示詞引導角色動作或切換場景。
- **文字與相機控制**　可交錯使用文字提示與相機軌跡，控制後續事件與視角。
- **長世界生成**　逐段接續生成最長 60 秒的連續影片。
- **世界記憶**　視角移開再回到原處時，保留先前的物件、背景與空間資訊。
- **風格與視角**　支援真實影像、CG、遊戲與動畫風格，以及第一人稱、第三人稱跟隨或旁觀視角。

## 生成架構

1. **Prompt Enhancer** 根據文字與相機輸入規劃下一段提示詞及片段長度。首輪建立主體與環境，後續依完整對話與影片歷史描述變化。相機控制輪另將軌跡送入影片模型。
2. **自回歸 DiT** 以少步去噪逐段生成影片。KV cache 與持續延長的影片前綴將上下文帶到下一輪。
3. **Action-aware causal attention** 在片段層級遮住未來片段。場景描述保持可見，動作文字僅在所屬片段的標註時間窗內可見。

## Segment Forcing 訓練

- 每段計算 flow-matching loss 後立即進行反向傳播，只保留當前片段的計算圖。
- 用一步低噪聲估計更新 KV 歷史，供後續片段使用，讓模型在訓練時接觸自身的預測誤差。

## 依問題取用

- 說明互動流程時，依序描述首輪如何建立場景、後續如何用文字或相機軌跡控制片段，以及重訪場景時如何延續世界記憶。
- 比較方法時，用 Action-aware causal attention 說明動作文字的生效範圍，用 Segment Forcing 說明訓練如何把生成誤差帶入後續片段。
