# 圖表驗收

以輸入方法與圖說為真源。對照實際 PNG，逐項記錄 PASS／FAIL／未檢；無法閱讀圖片時不能宣稱視覺驗收通過。

| ID | 條件 |
|---|---|
| Q1 | 必要元件齊全；沒有憑空增加模型、數據、結果或研究結論 |
| Q2 | 每條有向邊的來源、終點、方向符合來源；無多餘連線或錯誤迴圈 |
| Q3 | 名稱、縮寫、公式、圖例與文字語言一致；無拼錯或無意義文字 |
| Q4 | 正常顯示尺寸可讀；文字不重疊、不截斷，箭頭與色彩可辨識 |
| Q5 | 分組、先後順序及核心訊息符合圖說；不為美觀刪除必要邏輯 |
| Q6 | PNG 可解碼、尺寸合理；本次全部預期候選已產生，非舊檔 |

數值圖另核對資料點、單位、尺度、標籤、誤差棒與統計定義，保留原始資料及繪圖程式。沒有原始數據就不製造定量結果。

修訂使用穩定 ID，例如「Q2 FAIL：reranker 連回 retriever 與來源不符」。最多兩次額外修訂；保留原檔，只針對已確認缺口修改並重新檢查。

交付紀錄：來源檔、圖說、repo revision、模型、候選數、critic 輪數、實際路徑、驗收項與未解決問題。避免保存 API key。美觀不等於內容正確。
