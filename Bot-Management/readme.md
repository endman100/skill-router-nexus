# Bot 管理（Bot Management）

此分類涵蓋 Bot 建立與重新部署、共用連線授權、持久狀態搬移及自動化驗收。適用於需要恢復 Bot 環境或讓團隊 Bot 重用部署流程的場景。

- [X 共用連線授權指南](x-shared-connection-guide/X共用連線授權指南.md)涵蓋 LinkingAI Chrome、X OAuth、書籤實測、已見清單搬移與排程驗收。

分類決策為 `CREATE_CATEGORY`。這份指南的主要用途是恢復 Bot 的共用連線、持久狀態與排程，跨越現有的社群媒體操作、MCP 工具管理和雲端部署的範圍。這些工作同樣適用於其他 Bot。目前有一份指南，維持單層。
