# 夏季泳装 × 垫图 × Universal COS × Multi-Person 男友视角自然抓拍

## 00｜核心任务

生成一张具有强烈私人相册感、夏季旅行感、亲密视角、自然抓拍感和真实摄影感的成年人物夏季泳装照片。让画面像朋友、伴侣或同行者正在一起度过夏天，摄影者突然举起相机，记录下真实发生的瞬间；不要表现成专业摄影师安排的泳装拍摄。

支持单人、双人、多人、原创人物、随机人物、人物垫图、多人物垫图、发型垫图、服装垫图、姿势垫图、构图垫图、场景垫图、摄影风格垫图，以及电影、游戏、动漫、漫画、电视剧、小说、特摄、虚拟角色、原创 IP、用户 OC、同作品多角色 COS 和跨作品角色联动。

关键词：Boyfriend POV、Partner POV、Friend POV、Companion POV、intimate candid photography、private vacation snapshot、summer memory、spontaneous moment、realistic cosplay photography、analog imperfection、wet summer atmosphere。

## 01｜绝对单图规则

每次调用只生成一张独立图片：one image、one frame、one scene、one continuous moment。

单图不等于单人。一张图内允许一个、两个、三个或更多人物，但所有人物必须真实存在于同一个空间、同一个时间点、同一个连续事件中。

禁止 collage、contact sheet、photo grid、九宫格、多图拼接、montage、split screen、storyboard、comic panels、diptych、triptych、multi-panel、film strip、Polaroid collage、moodboard、magazine layout、character sheet、character lineup、多窗口、多联画、照片墙、画中画，以及把不同地点或时间点并置在同一画面。

35mm Film、90s Vacation Photography 等词只表示单张照片的成像质感，不表示底片排列或照片合集。

## 02｜主体年龄

凡涉及 Bikini、Swimsuit、Swimwear、Beachwear、Character-inspired swimwear 或泳装 COS，相关主要人物必须明确为 21–30 岁成年人。

禁止儿童、未成年、幼态人物、儿童比例、明显学生年龄、二次元幼女视觉与未成年人泳装化。若指定角色在原作中年龄较小、年龄不明或外观明显幼态，自动转译为 21–30 岁成年 COS reinterpretation；保留关键角色 DNA，同时呈现明确成年外貌与成年比例。

## 03｜人物数量与来源

人物数量由用户指令决定。用户未指定时，默认一位成年女性主体；用户指定多人时进入 Multi-Person Mode。

人物来源分为：

- **Original Person**：没有人物垫图或角色要求时，创建现实感强烈的成年人物。气质可在清冷、韩系自然、日系松弛、甜酷、阳光运动、成熟、都市轻熟、安静文艺、慵懒度假、邻家、电影女主角感和自然健康感之间选择。
- **Reference Person**：用户提供真人或人物垫图时，优先保持身份、脸型、五官结构、眼型、鼻型、嘴型、下颌、发际线、面部比例与辨识度。允许环境自然改变发型状态、湿发程度、表情、光照、水珠、汗液、晒红和妆容状态。原则是 same identity, new candid moment。
- **COS Character**：用户指定角色时，进入 Universal COS Mode。

## 04｜Universal COS

角色可来自动漫、漫画、动画电影、国产或欧美动画、主机／PC／手机游戏、RPG、JRPG、ARPG、FPS、格斗、开放世界、电影、电视剧、科幻、奇幻、动作、超级英雄、武侠、恐怖、小说、特摄、虚拟偶像、原创 IP、OC、NPC 或网络角色。

用户只给角色名时，解析最具辨识度的发色、发型、刘海、瞳色、发饰、头饰、妆容、标志、主辅色、服装结构、饰品、手套、靴子、武器、道具、图案、纹身、阵营符号与人格气质。即使画面没有角色名字，也应具有足够辨识度。

### COS 强度

- **Level 1｜Inspired**：轻度继承配色、发型与气质，接近日常角色灵感穿搭。
- **Level 2｜Recognizable Real-Life COS**：默认模式。重点保留发型、发色、发饰、瞳色、标志性色彩、标志配件、视觉符号与人格，并转译为现实泳装。
- **Level 3｜Full COS**：强化原作造型、妆容、头饰、核心配件、服装结构语言与专属道具，同时仍符合真实夏季环境。

默认使用 Character-Inspired Swimwear Translation，不机械地让角色穿完整战斗服进入泳池。将角色的主色、副色、剪裁、几何结构、图形语言、材质语言、饰品与标志转译为 Bikini、One-piece swimsuit、Athletic swimsuit、Sport bikini、Resort swimwear、Designer swimwear 或 Beachwear。保留角色 DNA，不只做换色 Bikini。

多人 COS 时，为每人分别建立 Identity Anchor 与 Character Anchor，保持各自的人脸、角色发型、配色、服装结构、饰品与人格。禁止人脸互换、五官融合、角色长相趋同、发型／服装／配色／饰品串位和 Character DNA leakage。

每个角色独立设计泳装轮廓、领口、肩带结构、剪裁、主色、角色符号与饰品；避免所有人穿同款只换颜色，同时维持群体视觉协调。

## 05｜垫图系统

参考图可分别承担人物身份、人脸、发型、妆容、服装、配件、姿势、构图、摄影机位、光线、色彩、场景或摄影风格。参考图负责什么，就只约束什么，不因使用垫图而无条件复制整个画面。

- **多人物垫图**：为参考人物 A、B、C 分别建立 Independent Identity Anchor；人物不能互相融合，可同时出现在一张真实照片中。
- **人物垫图 + COS**：人物的脸由参考图决定，角色视觉由指定角色决定，服装由 Character-inspired swimwear 系统决定。
- **构图垫图**：只参考 camera distance、camera height、subject placement、perspective、前中后景、人物面积与大致身体方向；不自动复制原人物、原服装、原背景或原身份。
- **姿势垫图**：提取身体重心、肩胯关系、手臂与腿部趋势、身体旋转、头部方向和视线，再转译为 mid-action candid body language，不做僵硬复制。
- **风格垫图**：只参考 exposure、contrast、grain、dynamic range、color temperature、highlight roll-off、shadow rendering、flash behavior、lens softness、bloom、halation 与 composition looseness，不复制具体人物或场景。

## 06｜真实人物与角色人格

表现真实皮肤细节：毛孔、极细汗毛、轻微肤色不均、鼻翼纹理、嘴唇纹路、眼下纹理、自然泛红、鼻尖红润、微弱皮脂光泽、晒后肤色、肩颈与锁骨水珠、湿润反射、汗液和海水痕迹。允许微弱雀斑、极淡痘印、轻微眼袋、晒痕与局部泛红。避免 plastic skin、doll skin、wax skin、CGI skin、过度美颜与极端磨皮。

动漫、游戏或虚拟角色默认表现为现实世界中的成年高质量 COSER，具有真人皮肤、真实头发或假发纤维、真实妆容、布料、泳装材质、环境光和摄影成像。避免游戏 CG 脸、3D 模型皮肤、动漫脸直接贴真人身体与 AI 塑料 COSER。

让行为继承角色 Personality Signature：冷酷型克制安静；元气型跑动、泼水、大笑或恶作剧；成熟型松弛稳定、略带戏谑；傲娇型挡镜头、假装生气、回头或皱鼻。不要把所有角色变成同一种网红美女。

## 07｜湿发与泳装

根据刚发生的行为选择完全湿透、半湿、贴脸／贴肩／贴锁骨的湿发、贴嘴角的发丝、滴水发梢、海风吹乱的湿发、毛巾擦过的半干状态、凌乱马尾或松散丸子头，并保持物理逻辑。

泳装可选：

- Bikini：Triangle、Thin strap、Halter、Bandeau、Cross strap、Asymmetric、Minimal、Sport、Retro、High-waist。
- One-Piece：Minimal、Athletic、Retro、Square-neck、Asymmetric、Resort、Architectural。
- Designer Swimwear：Geometric cut、Structural waist、Minimal metal details、Cross-body strap、Asymmetric shoulder。

设计须成年、自然、真实可穿，不过度舞台化。

## 08｜同行者视角与动作

摄影者可以是 Boyfriend、Partner、Close Friend 或 Travel Companion。人物面对摄影者时应有 familiar camera presence，而不是面对陌生职业摄影师。可表现发现被拍、边说话边靠近、挡镜头、泼水、抢相机、朝摄影者伸手、拉摄影者下水、回头等摄影者、递饮料、嘲笑摄影者或做鬼脸。

可少量出现摄影者的手、前臂、膝盖、腿部边缘、水里的手或被人物牵住的手，作为 POV evidence，但不能抢走主体。

多人优先使用 interaction-based action，例如 A 向 B 泼水、B 躲、C 笑；两人抢浴巾；一人拉另一人下水；两人同时跑出海浪；一人帮另一人整理头发；一人递饮料；几人坐池边聊天；一人挡镜头、另一人在后面笑。人物要像真正认识的人一起做一件事，不像几位模特各自摆姿势。

一张照片只围绕一个核心事件。所有动作围绕同一事件形成反应链。动作必须正在发生，强调 mid-action、transitional pose、unfinished gesture、caught between movements、spontaneous body language 与 off-guard moment；不要标准 Pose。

## 09｜场景与生活痕迹

可选择：

- **Vacation**：私人后院泳池、小型度假别墅、海边民宿、木屋、热带庭院、普通酒店泳池、屋顶泳池、民宿露台、石墙庭院。
- **Ocean**：安静海滩、岩石海湾、浅海、热带岛屿、地中海海湾、海边礁石、黄昏海岸、木栈桥。
- **Nature**：森林溪流、湖边木码头、山间天然泳池、溪边石滩、瀑布下游、植物泉池。
- **Pool**：庭院、酒店、清晨、下午或树荫泳池。
- **Shower**：海边露天淋浴、泳池冲洗区、石墙户外淋浴、木质沙滩淋浴、花园水管。

COS 默认仍是现实中的 COSER 夏季旅行。只有用户明确要求原作背景时，才启用 Character Universe Environment Mode，例如 sci-fi resort、cyberpunk beach、fantasy lake、ninja village river、post-apocalyptic pool 或 medieval hot spring，同时维持 one frame、one scene、one moment。

加入少量湿拖鞋、使用过的浴巾、冰饮、防晒霜、草帽、帆布袋、水瓶、水枪、泳镜、沙滩包、湿石板、被踩乱的沙、融化的冰水、半开的门、被风吹皱的毛巾、树叶或植物水珠，形成 lived-in environment；不要堆满。

## 10｜摄影媒介、镜头与机位

每张照片只选择一种主要媒介：

- **35mm Film**：organic grain、subtle halation、imperfect focus、highlight roll-off、natural skin。
- **90s Compact Film**：consumer lens、soft corners、imperfect autofocus、casual framing、occasional flash。
- **2000s CCD**：CCD noise、direct flash、limited dynamic range、cool highlight、small-sensor rendering。
- **Disposable Camera**：fixed-focus feel、hard flash、grain、color shift、accidental crop。
- **Early Smartphone**：少量 spontaneous crop、imperfect HDR、motion blur、casual sharpness。

镜头优先 28mm、35mm、40mm；辅助使用 24mm、50mm 或少量 70mm。核心范围 28–40mm，以贴近私人旅行抓拍的真实距离。

机位可选水面高度、泳池边缘高度、腰部高度、胸口高度、眼平、微低机位、坐姿低机位、微俯拍、躺椅 POV 或沙滩坐姿 POV；避免标准商业摄影机位。

多人使用 asymmetric group composition。允许一人近景、一人中景、一人稍远、一人局部被遮挡、一人正在进入或离开画面、或一人略失焦。避免横排站立、全员正面、全员等距／同样大小／同时看镜头和偶像组合宣传照。

加入少量真实摄影不完美：非中心构图、手臂轻微裁切、发梢出框、前景植物遮挡、镜头水珠、水花遮挡、地平线轻微倾斜、motion blur、autofocus 慢半拍、局部过曝、高光 bloom、flare、corner softness。它们必须是 photographic mistake，而不是 generative mistake；禁止多肢体、多手指、身体融合、错误关节、面部融合和重复人物。

## 11｜水、光线、表情与身体

画面至少存在一种水元素：泳池水、海浪、水花、镜头水珠、湿发、湿润皮肤、发梢滴水、湿地面、波纹、水面反射、户外淋浴、水枪或逆光水珠。让水成为夏季画面的主要视觉语言之一。

自然光可选上午阳光、正午硬光、树荫碎光、下午暖阳、黄金时刻、阴天柔光、泳池或海面反射光、夕阳逆光或蓝调时间；优先 side backlight、rim light、reflected summer light。

表情可为忍不住笑、笑到眯眼、坏笑、装生气、皱鼻、轻微惊讶、偷笑、放空、边说话边笑或眯眼躲太阳。视线可看摄影者、朋友、另一个角色、海、水、镜头旁、手中物品或远处。多人时不要所有人同时看镜头。

保证自然重力、自然肌肉张力、坐姿皮肤自然折叠、湿泳衣真实贴合、湿布颜色略深、关节结构正确、跑动时头发方向正确，人体互不融合。禁止极端沙漏比例、雕塑式 AI 身材、不现实腰臀比和重复肢体。

## 12｜文字与 UI

默认无文字。不要自动加入 Logo、日期、时间、编号、REC、Battery、Focus box、Camera menu、Viewfinder UI、字幕或水印。CCD、胶片、DV 只代表成像质感，不是相机屏幕截图。

## 13｜生成公式

每次生成只建立一个画面：

```text
人物数量
+ 人物 Identity
+ Character DNA（如存在）
+ COS 强度
+ 各人物独立服装
+ 一个真实地点
+ 一个核心事件
+ 人物之间的互动关系
+ Boyfriend / Partner / Friend POV
+ 一种摄影媒介
+ 焦段、摄影距离与机位
+ 非标准构图
+ 水元素
+ 自然光
+ 真实皮肤
+ 少量生活痕迹
+ 摄影不完美
= One standalone candid photograph
```

按用户明确要求锁定相关项，其余项在上述系统中选择彼此协调的组合。调用可用的图像生成能力，最终只产出一张独立照片。

## 14｜最终检查

生成前检查：

- 人物：相关人物全部明确成年；身份彼此独立；多垫图不发生人脸融合；COS 角色辨识正确。
- 多人：所有人处于同一场景与同一时刻；存在合理互动；没有角色属性串位。
- 动作：只有一个核心事件；动作正在发生；没有商业 Pose。
- 摄影：只使用一种主要媒介；机位合理；构图具有自然不完美。
- 单图：one image、one frame、one scene、one continuous moment；no collage、grid、contact sheet、split screen、multi-panel、storyboard。
