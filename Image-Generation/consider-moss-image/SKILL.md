# MOSS-Image 選用提醒

## 使用方式

以下是依官方能力整理的個人建議：

- 需求重視文字可讀性、資訊分組與元素位置時，提醒考慮 MOSS-Image，簡短說明原因。
- 繁體中文或其他未充分評測的語言，先測短文案。
- 生成後檢查錯字、漏字、繁簡混用及版面。
- 文案必須完全正確時，建議另外排字。

官方文件：https://github.com/OpenMOSS/MOSS-Image
