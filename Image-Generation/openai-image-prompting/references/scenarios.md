# 场景模板

以下为原创示例，替换演示文案和对象，保留用户真实要求。官方案例见 [Image prompting](https://developers.openai.com/api/docs/guides/image-prompting)。

## 新图

| 任务 | 输入要点 | 验收重点 |
|---|---|---|
| 摄影、电影感场景 | 主体、动作、机位、环境光 | 人体、接触关系、景深 |
| 广告、贺卡 | 文案清单、阅读顺序 | 漏字、重字、裁切 |
| Logo、商品包装 | 品牌资产、使用尺度、文件类型 | 小尺寸辨识、包装结构；位图不冒充矢量 |
| 历史情境 | 地点、年代、可靠参考 | 将视觉合理性与史实核验分开 |
| 漫画、角色系列 | 格数、每格事件、角色参考 | 连续性、人物数量、角色一致 |
| 教学图、幻灯片、图表 | 已核实的标签、数值、关系 | 单位、箭头、图例；图片不冒充可编辑文件 |

### 摄影

```text
为陶艺工作室主页制作横幅照片。青年陶工坐在窗边修整一只未烧制的碗，
双手和碗口清楚可见。右侧保留约三分之一安静墙面用于网页文字。
阴天窗光，灰蓝工作服，桌上少量湿陶土。皮肤与工具有自然纹理。
网页文字由页面叠加，图片本身不要出现文字。
```

### 精确文案

```text
制作社区种子交换活动海报。标题为“让种子旅行”，出现一次；
小字为“周六 14:00｜社区花园”，出现一次。上半部标题，下半部三只种子纸袋插画。
米白纸张底色，墨绿字体，留出印刷安全边距。只使用以上两条文案，保持标点与数字。
```

### 漫画

```text
绘制横向三格无字漫画，以附件中的圆耳灰兔为主角。
第一格：灰兔抱着比自己高的向日葵花盆。
第二格：花盆挡住视线，灰兔绕开石头。
第三格：花盆放在窗边，灰兔坐下喝水。三格沿用同一灰兔外观与服饰。
```

## 编辑

| 任务 | 输入组织 | 易漏检查 |
|---|---|---|
| 翻译文字 | 替换表与版式约束 | 译文完整、原语言残留 |
| 风格迁移 | 区分风格图与主体图 | 是否误搬风格图中的物件 |
| 换装、人物入景 | 身份与服装/场景参考 | 脸型、手部、穿着关系 |
| 多图组合 | 来源元素与目标位置 | 输入顺序、比例、遮挡 |
| 产品去背 | 产品保持项与输出要求 | 真透明、白边、标签 |
| 草图写实化 | 空间结构与材质说明 | 透视、尺寸、额外物件 |
| 删除物件、更换家具 | 精确定位与周围保留项 | 残影、地面、接触阴影 |
| 连续修订 | 已接受图与本轮变更 | 旧问题是否回归 |

### 局部修改

```text
编辑图 1：把左下角红色水壶改为深蓝色。保持水壶形状、位置、反光及标签不变。
保留桌面、背景、相机角度与其余物体颜色。此次不改变其他内容。
```

### 双参考合成

```text
图 1 是目标书桌场景，图 2 是台灯产品参考。
将图 2 台灯放在图 1 显示器左边空位，底座接触桌面，比例与显示器协调。
保留台灯的灯罩轮廓、底座和开关位置；沿用图 1 视角与光照。
保留图 1 的显示器、书本与窗外景色。
```

## 故障处理

- 文字错误：定位具体字和区域，不同时重设计全图。
- 身份漂移：回到已接受的参考图，重新指定本轮变更。
- 布局错误：检查位置描述是否矛盾，降低无关装饰优先级。
- 图表错误：回到经过核实的数据；需要可编辑交付时使用相应文档或图表工具。
- 必须局部像素不变：作为独立工程需求，使用符合宿主工具规则的合成流程并验证未编辑区域。
