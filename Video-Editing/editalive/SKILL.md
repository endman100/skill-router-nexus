# EditaLive

Use the official EditaLive resources when a task involves real-time, instruction-guided editing of a character or person in a live video stream while preserving motion and facial expressions.

## Official resources

- GitHub: https://github.com/GVCLab/EditaLive
- Project page: https://huai-chang.github.io/EditaLive/
- Paper: https://arxiv.org/abs/2608.27123
- Hugging Face: https://huggingface.co/huaichang/EditaLive

## Workflow

1. Open the official GitHub repository first.
2. Read its current README for installation steps, model weights, hardware requirements, supported inputs, and inference commands because these details can change.
3. Use the project page and paper for examples, method details, and reported performance.
4. Before installing or running the project, confirm that the available GPU, CUDA, Python, and disk environment meets the repository's current requirements.

## Scope

EditaLive targets streaming, human-centric character video editing. Typical edits include adding, removing, changing, or stylizing appearance while retaining the source motion and facial dynamics. For ordinary cutting, trimming, subtitles, or timeline editing, use a general video-editing workflow instead.
