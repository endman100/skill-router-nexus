# Document Generation

此分類涵蓋 PDF 生成與轉換、文件自動化產出、範本渲染、OCR 文字辨識、CMS 內容管理、以及各種文件格式（Excel、Word、PDF）的處理。適用於需要批量生成文件、轉換文件格式、或自動化文件工作流的場景。

## 文件翻譯

圖片／掃描件翻譯及原文與譯文對照 PDF，使用 Writing-and-Content 的單一 [translate Skill](../Writing-and-Content/translate/SKILL.md) 及其文件處理參考。此分類不再保留另一份翻譯 Skill 或轉送 Router；一般 PDF／Word／試算表處理工具維持原用途。
